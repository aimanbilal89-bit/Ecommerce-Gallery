# ShopEase - E-Commerce Product Gallery

## Web Engineering Lab 8

This project is created for Web Engineering Lab 8.

### Project Files
- index.html: Contains the HTML structure.
- style.css: Contains styling and CSS Grid layout.
- README.md: Project documentation.

### Features
- Responsive E-Commerce Product Gallery.
- CSS Grid Layout.
- Uses auto-fit and minmax().
- Minimum product card width of 250px.
- Hover animations on product cards.
- Responsive design without media queries for the product grid.

### Technologies Used
- HTML5
- CSS3
- CSS Grid
- Git and GitHub

### How to Run
1. Open index.html in a browser.
2. Alternatively, use Live Server in VS Code.
